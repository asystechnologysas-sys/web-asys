Información

Cuando usted comparte datos a través del formulario o corresponde con la empresa, esos datos se utilizan para atender solicitudes comerciales, administrativas y legales.

Seguridad y conservación

Se mantienen medidas razonables de seguridad para evitar uso indebido, pérdida o acceso no autorizado. Los datos se conservan el tiempo estrictamente necesario para las finalidades descritas.
